# Bot HR — Design Record

Chosen style: an illustrated office complaint department. This uses the approved original paper character rather than adopting a famous meme's likeness.

- Palette: warm cream paper #FBF1DA, off-white sheets #FFFAF0, ink #191916, cyan chat cues #09A9C4, coral-red verdicts #E6503F, tan desk accents #DDC6A2.
- Typography: bold system sans-serif for readable headlines and buttons; Courier New for file labels. No font service or install.
- Layout: pinned compact header; full-width 3:1 desktop banner; transparent mascot and live main line on mobile; five numbered 7:3 story rows; square meme archive; community break room; token details in a native dialog.
- Interactions: smooth anchor scrolling, reduced-motion support, accessible dialogs, local PNG downloads, caption copying, exact address copying, and configured external links.
- Image rules: natural aspect ratios, editable live captions, full dialogue and verdict visibility, all five distinct narrative actions preserved.
- Build choice: vanilla HTML/CSS/JavaScript with Node's built-in modules for preview, checks, and static export. No npm dependencies.

Reference lessons, inspected through public project pages: Wojak emphasizes expressive character variations and a meme-generator entry point; NPC offers scene variations and community customization/gallery entry points. The inference for Bot HR is to place its character and reusable jokes ahead of dense token copy, with lightweight download/copy participation. These observations do not establish visitor engagement or token demand.
